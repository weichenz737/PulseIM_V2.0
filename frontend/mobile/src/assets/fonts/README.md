# Material Symbols Outlined

`material-symbols-outlined.woff2` is a local subset of Google's Material Symbols Outlined variable font (v377). It contains the icon ligatures used by the mobile client as of 2026-10-20. The subset was generated with the Google Fonts `icon_names` parameter so the app does not request an external font at runtime.

When adding a new icon name, regenerate this subset with an alphabetically sorted list of the names used in `frontend/mobile/src`. The CSS family name must remain `Material Symbols Outlined`. See the [Google Material Symbols guide](https://developers.google.com/fonts/docs/material_symbols) and the accompanying license.
